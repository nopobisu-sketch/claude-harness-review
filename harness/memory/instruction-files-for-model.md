에이전트가 읽는 지시문(CLAUDE.md·스킬·규칙 파일)을 새로 쓰거나 고칠 때는 **모델 쪽에 조금이라도 나은 방향**을 고른다. 어느 프로젝트에나 통하는 범용 규칙은 짧은 영어 문장으로 쓰고, 프로젝트 고유 용어·훅과 시험이 가리키는 절 이름·사고가 날 때마다 다듬은 문장(장치 표 등)은 한국어 그대로 둔다.

**Why:** 2026-11-19 프로젝트 E 세션에서 지시문 점검 결과를 적용하던 중 사용자가 «혹시 claude.md는 영어로 써야 더 나은가? 모델이 토큰 덜 먹고 맥락 잘 이해하는 방향으로 해줘», 이어서 «조금이라도 나은 방향으로 부탁함»이라고 했다. 사람이 읽기 편한 쪽보다 모델 효율을 앞에 둔다는 뜻이다. 같은 뜻이면 한국어가 영어보다 토큰을 더 쓴다는 것은 추정이고 실측은 못 했다(맥에 토큰 세는 도구·API 키 없음).

**How to apply:**
- 새로 쓰는 범용 규칙은 영어로, 이유를 붙인 짧은 문장으로. 금지문 나열 대신 «왜»가 붙은 서술.
- 기존 한국어 지시문을 통째로 영어로 옮기는 것은 사용자가 시킨 적이 없다(내 해석: 번역으로 뜻이 달라질 위험이 줄어드는 토큰보다 크다고 보고 하지 않았고, 원하면 말해 달라고 보고했다). 통째 번역은 사용자가 요청할 때만.
- 사용자에게 보이는 글(답·이슈·PR)은 이 규칙과 무관하게 한국어다.
- 지시문이 낡았는지 점검하는 도구는 `/doctor prompt-audit [경로]`다. 사용자가 입력창에 치는 명령이며, 보고서와 수정 제안만 내고 파일은 고치지 않는다([[user-typed-skills]]).
