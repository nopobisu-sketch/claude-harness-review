사용자가 아이디어를 연달아 던질 때는 분석·추천·질문을 붙이지 말고 받아적기만 한다. 아이디어는 사용자 표현 그대로 그 주제의 파일에 추가하고, 답은 «적었어요» 정도로 짧게 한다. 내 제안은 메모에 섞지 않는다.

**Why:** 2026-11-07 프로젝트 D 대시보드 폴더에서 행사 아이디어(`행사_아이디어.md`)를 말하는 동안 매번 긴 기획 답변을 붙였더니, 사용자가 «받아적기만 해, 자꾸 답변하지 마»라고 했다. 11-23 정리 때 어느 프로젝트에서나 통하는 업무 방식이라 전역으로 옮겼다.
**How to apply:** 사용자가 정리나 의견을 요청하기 전까지는 받아적기만 한다. 선택지에 번호·추천을 다는 전역 규칙은 사용자가 결정을 물을 때 쓰는 것이고, 받아적는 동안에는 쓰지 않는다. 관련: .
