만든 사람이 «저작권 없는 효과음»·«무료 다운로드»처럼 써도 된다고 밝혀 둔 소리·그림은, 따로 이용 조건 파일이 없어도 앱에 넣어 써도 된다(사용자 판단, 2026-11-10).

**Why:** 사용자가 직접 «이런 문구 있는 곳은 가능함»이라고 정했다. 유튜브 채널의 효과음을 만든 사람이 올린 다운로드 링크에서 받아 썼다.

**How to apply:** 이런 문구가 있으면 허락을 다시 묻지 말고 쓴다. 대신 PR 본문과 앱 안 출처 칸에 출처(영상·채널·링크)는 꼭 적는다. 유튜브에서 직접 뜯지 말고, 만든 사람이 올린 다운로드 링크에서 받는다. CC BY처럼 표기 조건이 있으면 그 조건을 따른다. 상업 이용을 막는 문구가 있으면 쓰지 않는다.
