**장치:** 아티팩트를 발행하면 `~/.claude/hooks/artifact-precheck.mjs`(PreToolUse Artifact)가 먼저 페이지의 인라인 스크립트(type 없음·module)와 `files`의 .js·.mjs를 `node --check`하고 U+2028·U+2029 글자를 찾는다. 문제가 있으면 발행을 막고 어디가 틀렸는지 돌려준다. 2026-11-25 사용자 «1235 반영해»로 메모리 지침을 이 훅으로 옮겼다(이슈 claude-harness#4, 원문은 `docs/archive/memory-2026-11-25/artifact-page-checks.md`). 훅은 문법만 본다. 커넥터·데이터가 붙은 동작은 헤드리스 Chrome에 가짜 `window.claude.use(...)`를 넣어 띄워 봐야 안다.

**사례(2026-11-14):** 한 아티팩트 페이지(프로젝트 E의 한 페이지)의 판 2·3이 정규식 안의 U+2028·U+2029 글자 때문에 문법 오류로 한 줄도 안 돌았다. 화면은 HTML의 «불러오는 중»에 멈췄고, 감독 세션은 커넥터 탓으로 보고 두 번 헛고쳤다. `node --check` 한 번이면 잡혔다.

**함정:**
- Write·Edit 도구 입력에 «백슬래시 u 2028»을 그대로 적으면 JSON 이스케이프로 풀려 파일에 실제 줄 구분 문자가 들어간다(11-14 재현). 코드에는 `String.fromCharCode(0x2028)`처럼 번호로 쓴다.
- 아티팩트가 커넥터를 쓰는 기능은 공식 도움말상 웹·데스크톱만이다. Claude 폰 앱에서는 안 되므로 폰에서는 브라우저로 claude.ai를 연다. 폰 흉내(375px·안드로이드 UA)로는 읽기가 됐다(11-14).
- «쓸 때마다 승인» 설정의 커넥터 도구는 아티팩트에서 못 쓴다.
- 도움이 된 방법: 페이지 원본을 저장소에 두고 그 파일로만 발행하기, 페이지에 판 번호를 보이게 적기, 본 스크립트가 안 돌면 몇 초 뒤 알리는 작은 감시 스크립트.
