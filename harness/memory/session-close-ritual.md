**장치:** 사용자가 «여기까지»·«다음 세션에서»·«마무리하자»·«꺼도 돼»라고 쓰면 `~/.claude/hooks/session-signals.mjs`(UserPromptSubmit)가 마감 절차를 세션 앞에 넣는다. 절차는 잃을 것 확인(커밋·push·열린 PR·이슈·돌고 있는 일꾼), 다음 세션용 인수인계를 이슈·PR 코멘트에 남기기, 설정 변경은 새 세션부터 적용된다는 안내, «다음 세션에서»면 그 일을 지금 시작하지 않기다. 마감 때는 새 일과 정리 일꾼도 띄우지 않는다. 2026-11-25 사용자 «1235 반영해»로 메모리 지침을 이 훅으로 옮겼다(이슈 claude-harness#4, 원문은 `docs/archive/memory-2026-11-25/session-close-ritual.md`).

**실측:** 전사(2026-09-06, 1,134건 중 18건)에서 반복된 표현은 «오늘은 여기까지», «다음 세션에서 할게», «이제 이 세션 마무리하자», «다음 작업은 다음 세션에서 시작할거야 이제 이거 꺼도 돼지?»였다. 한 세션에 티켓 하나를 끝내고 다음은 새 세션으로 넘기는 리듬이다.

**Why:** 문맥 창이 차면 품질이 떨어진다는 걸 겪어서 알고 있고(«context 윈도우가 꽉 찼어 new session 열어서…», 2026-05-06), 세션을 갈아탈 때 무엇이 남았는지 몰라 잃는 것을 경계한다. «꺼도 되나?»는 예의가 아니라 잃을 게 없는지 묻는 것이다. 2026-09-06 권한·모델 설정을 바꿨을 때는 «설정은 새 세션부터 적용된다»가 가장 중요한 안내였다.
