# Claude 하네스

이 저장소(`~/.claude`)는 사용자가 Claude를 쓰는 모든 프로젝트에 공통으로 적용되는 업무 방식과 장치를 관리한다. 각 프로젝트는 여기에 자기만의 설정을 더해 쓴다.

## 층

**전역 하네스**:
`~/.claude`에 있는, 모든 프로젝트의 모든 세션에 닿는 규칙·메모리·장치·스킬의 묶음.
_Avoid_: 공용 설정, 전역 설정

**개별 하네스**:
한 프로젝트에만 닿는 규칙·스킬·장치·메모리의 묶음. 저장소 안의 지시문과 `.claude/`, 그리고 그 프로젝트 메모리로 이루어진다. «저장소»·«프로젝트»는 `~/Documents/GitHub` 바로 아래 폴더 하나를 가리키며, git 저장소가 아니어도 된다(git 없는 폴더는 프로젝트 메모리 폴더가 있을 때 목록에 든다). 경로는 한글 정규화(NFC) 기준으로 비교한다.
_Avoid_: 프로젝트 맞춤 하네스, 맞춤 하네스, 프로젝트 하네스

**전역과 다르게 하는 것**:
개별 하네스가 전역 하네스와 다르게 하기로 한 항목들. 프로젝트 메모리 목차 맨 위의 절에만 적고, 전역 규칙보다 우선한다.
_Avoid_: 개인화 설정, 오버라이드, 예외 규칙

**시작 요약**:
모든 세션이 시작할 때 세션 앞에 놓이는, 매번 지켜야 할 전역 규칙의 짧은 요약.
_Avoid_: core brief, 핵심 요약

## 장치와 갱신

**장치**:
규칙이 지켜지게 강제하거나 지켜지는지 재는 것(훅, 시험, 금지 규칙, 예약 작업, 점검 도구). 글로 적힌 규칙과 구별한다.
_Avoid_: 가드, 안전장치

**실측**:
점검 도구가 실제로 재서 얻은 상태와 그때의 시각. 손으로 옮겨 적은 값은 실측이 아니다.
_Avoid_: 확인됨, 반영됨

**하네스 문서 최신화**:
3일마다 전역 하네스에서만 도는 하나뿐인 예약 작업. 새 권장안을 조사하고, 사용자가 고른 제안을 전역 하네스에 반영한다.
_Avoid_: 순찰, 최신화 작업(프로젝트 E)

**정리**:
전역 하네스가 바뀐 뒤 그 프로젝트의 세션이 자기 개별 하네스를 맞추는 일. 예약 작업 없이 프로젝트 세션이 한다.
_Avoid_: 프로젝트 최신화, 동기화

## 하네스 지도

**하네스 지도**:
전역 하네스·장치·프로젝트의 실측 상태와 고를 제안을 한곳에 보여 주는 단 하나의 아티팩트.
_Avoid_: 워크플로 보드, 화이트보드, 프로젝트 E 워크플로

**권장안**:
바깥 출처(공식 문서, 프론티어 랩 발표, 커뮤니티)가 말한 하네스 방식 하나. 상태는 현행·시험·대체됨·버림이고, 지도의 색에는 현행만 셈한다.
_Avoid_: 권장 출처, 베스트 프랙티스, 모범 사례

**제안**:
우리 하네스를 이렇게 바꾸자는 안 하나. 권장안에서 나오기도 하고 겪은 일에서 나오기도 한다. 상태는 고를 것·하자·보류·안 함·끝남이다.
_Avoid_: 후보, candidate

**프로젝트 건의**:
프로젝트 세션이 일하다 찾은, 모든 프로젝트에 통할 규칙·도구 함정·장치 아이디어 하나. 프로젝트는 전역을 고치지 않고 그 프로젝트 메모리의 `global-proposals.md`에 건의로만 적는다. 전역이 거둬 지도에 «프로젝트 건의» 출처의 제안 카드로 올리고, 사용자가 고른다.
_Avoid_: 전역 제안(프로젝트 쪽에서 쓸 때), 요청, 티켓

**답칸**:
제안 카드 밑에서 사용자가 «하자 / 보류 / 안 함»과 조건을 적는 칸. 제안을 고르는 유일한 방법이다.
_Avoid_: 선택칸, 투표

## 사람과 세션

**감독**:
사용자가 직접 연 세션. 결정 대화·브리프·결과 확인만 하고 일은 일꾼에게 넘긴다.
_Avoid_: 감독관, 지휘자, 오케스트레이터, coordinator

**일꾼**:
감독이 일을 맡긴 세션이나 백그라운드 에이전트. 한 번에 끝나는 일은 백그라운드 에이전트, 맥락을 이어 가야 하는 일은 새 세션이 맡는다.
_Avoid_: 자식, 워커

**검토자**:
사용자의 하네스를 받아 읽고, 자기 환경에 깔아 돌려 보며 의견을 주는 바깥 사람. 사용자의 계정·저장소·메모리에는 접근하지 않는다.
_Avoid_: 리뷰어, 공유받는 사람

**검토 묶음**:
검토자에게 보내려고 전역 하네스에서 따로 꾸린 사본. 읽기용 설명과, 검토자 환경에 깔아 볼 수 있는 설치용 부분을 함께 담는다. 원본 저장소와 메모리를 그대로 넘기는 것이 아니다.
_Avoid_: 배포판, 공유본, 백업

**설정 폴더**:
Claude Code가 규칙·훅·메모리·설정을 읽는 폴더. 보통 `~/.claude`이고, 환경 변수 `CLAUDE_CONFIG_DIR`로 바꿀 수 있다. 검토자는 검토 묶음을 평소 설정 폴더가 아닌 따로 쓰는 설정 폴더에 깐다.
_Avoid_: 홈 폴더, 전역 폴더
